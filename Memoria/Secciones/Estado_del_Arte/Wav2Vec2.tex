\subsection{Wav2Vec2}
\label{subsubsec:eda_wav2vec}
Wav2Vec 2.0 es un modelo de aprendizaje profundo $end-to-end$ para el procesamiento de voz propuesto por Meta en 2020. Su principal objetivo es aprender representaciones acústicas directamente a partir de la señal de audio cruda, eliminando la necesidad de emplear características diseñadas manualmente.

El modelo se basa en aprendizaje autosupervisado, permitiendo aprovechar grandes cantidades de audio no etiquetado durante el preentrenamiento. Posteriormente, estas representaciones pueden adaptarse mediante fine-tuning supervisado para tareas específicas como el reconocimiento automático del habla.

Gracias a este enfoque, Wav2Vec 2.0 logra buenos resultados con pequeños conjuntos de datos.

\subsection*{Arquitectura y funcionamiento}

La primera etapa del modelo es un codificador convolucional multicapa que recibe como entrada la señal de audio cruda. Este codificador está formado por varios bloques convolucionales seguidos por capas de normalización y funciones de activación GELU (Gaussian Error Linear Unit) que transforman la señal de audio en una secuencia de representaciones latentes continuas.

Estas representaciones se introducen en un Transformer\footnote{Transformer es un modelo de aprendizaje automático usado en procesamiento de lenguaje natural diseñado para entender y generar secuencias de forma eficiente.} que incorpora la información temporal y produce representaciones contextualizadas.

Paralelamente, las representaciones latentes también se discretizan mediante el $Gumbel Softmax$\footnote{Gumbel Softmax es una técnica utilizada en redes neuronales para aproximar el muestreo de distribuciones categóricas discretas de forma diferenciable.} para que actúen como objetivos durante el aprendizaje.

El proceso de preentrenamiento se divide en cuatro etapas:

\begin{enumerate}
	\item El codificador genera las representaciones latentes.
	\item Se enmascaran bloques consecutivos de dichas representaciones.
	\item El Transformer genera representaciones contextualizadas a partir de la secuencia parcialmente oculta.
	\item Para cada posición enmascarada, el modelo identifica la representación cuantizada correcta entre varios ejemplos negativos.
\end{enumerate}

Por último, la función de pérdida utiliza la similitud del coseno entre las representaciones contextualizadas y las representaciones discretizadas.

Tras el preentrenamiento, el modelo puede adaptarse a tareas específicas mediante aprendizaje supervisado. Para la tarea $Deepfake detection$ se utiliza la función de pérdida CTC(Clasificación Temporal Conexionista)\footnote{CTC es un algoritmo y función de pérdida utilizado en redes neuronales profundas para entrenar modelos de aprendizaje automático en tareas de modelado de secuencias cuando los datos de entrada y salida no están alineados.}a la que se le aplica una versión de SpecAugment (técnica de aumento de datos diseñada específicamente para el reconocimiento automático de voz) para evitar sobreajuste.

\subsection*{Innovaciones clave}

Una de las principales contribuciones del modelo es la capacidad de aprender directamente a partir de la señal de audio sin procesar, evitando la necesidad de extraer las características del audio.

Wav2Vec 2.0 incorpora un módulo de cuantización que transforma las representaciones continuas en unidades discretas del habla utilizando $Gumbel Softmax$.

\subsection*{Ventajas específicas para detección de deepfakes}

\begin{itemize}
	\item Al procesar directamente la señal de audio, el modelo puede detectar artefactos acústicos sutiles introducidos por sistemas de síntesis o conversión de voz.
	\item El modelo puede identificar inconsistencias temporales y patrones anómalos que pueden aparecer en grabaciones sintéticas.
	\item El modelo aprende automáticamente patrones relevantes para diferenciar entre voces reales y sintéticas, evitando las limitaciones asociadas a descriptores acústicos diseñados manualmente.
\end{itemize}
