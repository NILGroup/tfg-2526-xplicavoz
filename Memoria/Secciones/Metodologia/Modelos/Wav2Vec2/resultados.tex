Ahora vamos a procesar la salida del modelo para hacerla más interpretable, ya que ahora el modelo devuelve una tupla con dos valores de pertenencia a las distintas clases y lo que queremos es transformar eso en un número entre 0 y 1 que nos indique el grado de pertenencia del modelo a la clase generado. Cuanto más cercano a 1, más pertenece ese audio a la clase generado.

Para lograrlo, vamos a aplicar una función sigmoide para medir que tan mayor es x2 (clase generado) con respecto a x1 (clase real).

\frac{1}{1 + e^{-(x_2 - x_1)}}

X1: valor de pertenencia devuelto por el modelo a la clase 1.
X2: valor de pertenencia devuelto por el modelo a la clase 2.
