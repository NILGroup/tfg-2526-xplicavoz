\subsubsection{LightGBM}

LightGBM (Light Gradient Boosting Machine) es un framework de gradient boosting desarrollado por Microsoft en 2017 \cite{ke2017lightgbm} que optimiza el proceso de entrenamiento mediante innovaciones como el muestreo unilateral basado en gradientes (GOSS) y la agrupación exclusiva de características (EFB). A diferencia de Random Forest, que construye árboles de forma independiente y paralela, LightGBM los construye secuencialmente, donde cada nuevo árbol se especializa en corregir los errores de los anteriores.

\subsubsection*{Justificación del modelo}

LightGBM presenta ventajas significativas para la tarea de detección de deepfakes de audio:

\begin{itemize}
    \item \textbf{Alta precisión}: El enfoque secuencial de corrección de errores suele superar a los métodos de bagging en problemas complejos como la detección de deepfakes.
    
    \item \textbf{Eficiencia computacional}: El muestreo inteligente (GOSS) permite entrenar con grandes volúmenes de audios en menos tiempo que otros métodos de boosting.
    
    \item \textbf{Manejo de no linealidades}: Las firmas acústicas de las voces generadas por IA presentan patrones complejos que los árboles de decisión secuenciales pueden capturar de forma más efectiva.
    
    \item \textbf{Regularización integrada}: Los parámetros de regularización L1 y L2 ayudan a prevenir el sobreajuste cuando se trabaja con características de audio altamente correlacionadas.
    
    \item \textbf{Soporte nativo para datos desbalanceados}: Mediante el parámetro \texttt{is\_unbalance} o \texttt{scale\_pos\_weight}, LightGBM ajusta automáticamente los pesos de las clases.
\end{itemize}

\subsubsection*{Fundamento del algoritmo}

LightGBM construye los árboles de decisión de forma secuencial, minimizando una función de pérdida mediante el gradiente. A diferencia del boosting tradicional, introduce dos innovaciones clave:

\begin{itemize}
    \item \textbf{GOSS (Gradient-based One-Side Sampling)}: En lugar de usar todas las muestras para estimar la ganancia de información, GOSS retiene las muestras con gradientes grandes (aquellas con mayor error) y muestrea aleatoriamente las de gradiente pequeño. Esto reduce drásticamente el número de instancias a considerar sin perder precisión.
    
    \item \textbf{EFB (Exclusive Feature Bundling)}: Agrupa características mutuamente excluyentes (que raramente toman valores no cero simultáneamente) para reducir la dimensionalidad, crucial cuando se trabaja con características de audio de alta dimensión como los MFCC.
    
    \item \textbf{Crecimiento por hoja (leaf-wise)}: A diferencia del crecimiento nivelado tradicional, LightGBM expande el nodo con mayor pérdida, lo que produce árboles más profundos en las regiones problemáticas y más eficientes en las fáciles.
\end{itemize}

\paragraph{Early stopping}
Una ventaja importante de LightGBM es la capacidad de detener el entrenamiento cuando añadir más árboles no mejora el rendimiento en validación. Esto:
\begin{itemize}
    \item Previene el sobreajuste (overfitting)
    \item Ahorra tiempo computacional
    \item Determina automáticamente el número óptimo de iteraciones
\end{itemize}

\subsubsection*{Optimización de hiperparámetros}

LightGBM cuenta con un conjunto de hiperparámetros específicos, diferentes a los de Random Forest. La búsqueda se centró en aquellos que más influyen en el rendimiento:

\begin{itemize}
    \item \texttt{num\_leaves}: Controla la complejidad del modelo. Valores altos permiten capturar patrones más complejos pero aumentan el riesgo de sobreajuste.
    
    \item \texttt{learning\_rate}: Tasa de aprendizaje (eta). Valores pequeños requieren más iteraciones pero pueden lograr mejor convergencia.
    
    \item \texttt{n\_estimators}: Número de iteraciones de boosting.
    
    \item \texttt{min\_child\_samples}: Mínimo de muestras requeridas en una hoja. Controla la profundidad y evita hojas con pocas muestras.
    
    \item \texttt{subsample} y \texttt{colsample\_bytree}: Fracciones de muestras y características para cada árbol, introduciendo aleatoriedad.
    
    \item \texttt{reg\_alpha} y \texttt{reg\_lambda}: Regularización L1 y L2 para controlar la complejidad.
\end{itemize}

\subsubsection*{Métricas de evaluación}

Se emplearon las mismas métricas que en Random Forest para mantener la comparabilidad:

\begin{itemize}
    \item \textbf{Accuracy}: Proporción de predicciones correctas.
    \item \textbf{Precision}: Proporción de predicciones positivas correctas.
    \item \textbf{Recall}: Proporción de positivos reales correctamente identificados.
    \item \textbf{F1-Score}: Media armónica de precisión y recall.
    \item \textbf{AUC-ROC}: Área bajo la curva ROC.
    \item \textbf{MCC}: Coeficiente de correlación de Matthews.
\end{itemize}

La función de evaluación implementada es la misma que para Random Forest, garantizando consistencia en la comparación.

\subsubsection*{Análisis de importancia de características}

LightGBM ofrece dos tipos de importancia de características, complementarias entre sí:

\begin{itemize}
    \item \textbf{Gain}: Suma de la mejora (reducción de pérdida) que aporta cada característica cuando se usa en una división. Es la medida más informativa.
    
    \item \textbf{Split}: Número de veces que la característica se utiliza para dividir nodos. Indica la frecuencia de uso, no necesariamente su impacto.
\end{itemize}
